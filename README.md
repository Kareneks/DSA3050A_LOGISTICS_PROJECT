# DSA3050A_LOGISTICS_PROJECT
Power BI Project on E-Commerce Delivery Delays
## Project Overview
This project analyzes e-commerce delivery delays to identify bottlenecks in the supply chain.
**Author:** Karen Kisiang'ani
## Dataset Source
**URL:** https://www.kaggle.com/datasets/datascikhan/e-commerce-delivery-and-shipping-data-2026
*   **Rows:** 50,000
*   **Columns:** 30
*   **Licence:** CC0 Public Domain
## Methodology
*   **Week 1:** Data acquisition and problem framing.
*   **Week 2:** Power Query data cleaning and 8 transformations.
*   **Week 3:** Data modeling and DAX measures.
*   **Week 4:** Interactive Dashboard design.
*   **Week 5:** Final recommendations and presentation.
